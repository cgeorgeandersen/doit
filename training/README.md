# Responsible AI training deck

`CONA-Responsible-AI-Training.pptx` (38 slides, with trainer speaker notes on every slide) and a PDF copy.

Five modules, about 75 minutes: AI basics and Microsoft 365 Copilot; Microsoft's six Responsible AI principles and the three Sensitive Uses; using AI safely every day; governing AI projects with Microsoft's Cloud Adoption Framework (Assess, Document, Enforce, Monitor); and proving value. Ends with a knowledge check (answers in the notes), a 30-day plan and resources.

Before presenting, fill in the placeholders on slide 37 (portal link, AI review board contact, IT service desk), add names to slide 30, and check slide 20 against CONA's AI policy.

The deck uses a red/black/white Arial palette and a text wordmark only; drop it into the official CONA template to add logos.

To regenerate after editing content: `npm install pptxgenjs react-icons react react-dom sharp`, then `node build-deck.js CONA-Responsible-AI-Training.pptx`.
