# Cherokee Small Jobs

Website for Cherokee Small Jobs, a handyman company in Cherokee County, Georgia.

## Status: picking a design

`design-options/` holds four homepage mockups in red, white and black. Each is one self-contained HTML file, so you can open it straight in a browser with nothing to install:

| File | Direction |
| --- | --- |
| `design-options/index.html` | Overview of all four, side by side |
| `design-options/option-1.html` | **Shop Floor**: dark and industrial, with hazard tape and a services ticker |
| `design-options/option-2.html` | **Front Porch**: white and friendly, with a quick-quote card and a county map |
| `design-options/option-3.html` | **Hometown Badge**: awning, round badge logo, service-menu board, job-ticket form |
| `design-options/option-4.html` | **Punch List**: bold grid, where visitors tick jobs to build their quote request |

All four use the same copy and the same 12 service categories. The phone number, email, hours and reviews are placeholders, and the forms don't send anything yet.

Once a direction is chosen, the real site gets built in this folder and deployed as its own Vercel project with Root Directory `cherokee-small-jobs`, like the other sites in this repository.
